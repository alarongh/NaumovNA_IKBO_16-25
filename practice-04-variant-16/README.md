# Практическое занятие №4. Вариант 16

Выполнил Наумов Никита Александрович.

Группа ИКБО-16-25.

Преобразование учебного конфигурационного языка в TOML.
Разбор выполняет специализированная библиотека Lark 1.3.1.
Грамматика хранится в src/configlang/grammar.lark.

## Синтаксический разбор

Числа соответствуют [1-9][0-9]*, имена соответствуют [a-zA-Z]+.
Массив записывается как ({1, 2}), словарь как begin a := 1; end.
Константа объявляется var name значение;. Выражение имеет вид #[name + 1].
Поддерживаются вложенные массивы и словари.
