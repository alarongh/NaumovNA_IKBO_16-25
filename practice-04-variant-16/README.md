# Практическое занятие №4. Вариант 16

Выполнил Наумов Никита Александрович.

Группа ИКБО-16-25.

Преобразование учебного конфигурационного языка в TOML.
Разбор выполняет специализированная библиотека Lark 1.3.1.
Грамматика хранится в src/configlang/grammar.lark.

## Синтаксический разбор

Числа соответствуют [1-9][0-9]*, имена соответствуют [a-zA-Z]+.
Массив записывается как ({1, 2}), словарь как begin a := 1; end.
Константа объявляется var name значение;. Выражение имеет вид #[name + 1].
Поддерживаются вложенные массивы и словари.

## Установка и запуск

Нужны Python 3.11 или новее и зависимость из requirements.txt.
Команды выполняются в каталоге practice-04-variant-16.

```powershell
python -m pip install -r requirements.txt
New-Item -ItemType Directory -Force output
cmd /d /c ".\run.bat --output output/server.toml < examples/server.conf"
cmd /d /c ".\run.bat --output output/study.toml < examples/study.conf"
Get-Content output/server.toml
Get-Content output/study.toml
python -B -m unittest discover -s tests -v
```

В Linux используется перенаправление стандартного ввода оболочки.

```sh
python3 -B src/main.py --output output/server.toml < examples/server.conf
```

Ключ --output задаёт путь TOML. Родительский каталог должен существовать.
Вход читается из stdin в UTF-8, допускается BOM. При успехе код завершения
равен 0. Ошибки языка выводятся в stderr с кодом 1, ошибки параметров
argparse дают код 2. При ошибке преобразования прежний TOML сохраняется.

## Числа и вычисления

Исходный литерал является положительным целым без ведущих нулей.
Ноль и отрицательное значение можно получить вычитанием.
Операции + и - имеют одинаковый приоритет и выполняются слева направо.
Круглые скобки меняют порядок вычислений. Ссылки на константы используются
внутри #[...]. Константа должна быть объявлена до её использования.

concat принимает два массива и возвращает новый массив. len возвращает
число элементов массива или полей словаря. Вложенные выражения допустимы.
Например, #[len(concat(({1}), ({2}))) + 1] даёт 3.
Эти определения функций выбраны для типов данных варианта.

Константы объявляются перед итоговым значением или внутри словаря.
Каждый словарь создаёт область видимости. Внутри неё видны внешние
константы, локальная константа может перекрыть внешнюю.
Повторное объявление в одной области и повторное поле словаря дают ошибку.
Имена чувствительны к регистру. begin, end и var зарезервированы.
Комментарии и строки в синтаксисе варианта не определены.

## Выходной TOML

У корневого словаря поля становятся ключами TOML. Вложенные словари
выводятся как inline-таблицы, массивы сохраняют порядок элементов.
Корневое число или массив записывается под ключом value, поскольку
документ TOML состоит из присваиваний ключам.
Пустые массивы и словари поддерживаются. Итоговые целые должны
помещаться в знаковый 64-битный диапазон TOML.

## Примеры из двух предметных областей

В [server.conf](examples/server.conf) заданы число рабочих процессов,
порты и ограничения сервера. После вычислений получается следующий TOML.

```toml
workers = 4
ports = [8080, 8081, 9000]
capacity = 6
limits = { retries = 3, timeout = 30 }
```

В [study.conf](examples/study.conf) заданы номера занятий и учебные группы.

```toml
lessons = [2, 4, 6]
count = 3
remaining = 7
groups = [{ number = 16, students = 25 }, { number = 17, students = 24 }]
```

## Реализация и проверка

parser.py передаёт вход грамматике Lark и сообщает строку и столбец
синтаксической ошибки. evaluate.py обходит дерево и вычисляет константы.
toml_output.py формирует TOML, cli.py читает stdin и сохраняет результат.
При ошибке вычисления в сообщении есть позиция соответствующего узла.

На Windows с Python 3.14.7 прошли 10 тестов. Они покрывают все конструкции,
вложенность, области констант, обе функции, операции, неверные имена,
неправильные разделители, сохранение выходного файла при ошибке.
Результаты двух предметных примеров прочитаны модулем tomllib и сравнены
с вычисленными значениями.

Этапы грамматики, вычислений и вывода сохранены отдельными коммитами.
В задании для этой работы фиксированный список этапов не указан.
Сборка не требуется. Выходные файлы создаются в output и исключены из Git.

Грамматика использует LALR-разбор Lark.
[Документация Lark](https://lark-parser.readthedocs.io/en/stable/grammar.html)
