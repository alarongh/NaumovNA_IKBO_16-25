## Этап 1. REPL

Окно Tkinter показывает имя виртуальной файловой системы в заголовке.
Строка делится на команду и аргументы по пробельным символам.
Команда запускается клавишей Enter. Заглушки `ls` и `cd` выводят имя
и список полученных аргументов. `exit` закрывает окно.

## Запуск и проверка

Нужен Python 3.10 или новее с Tkinter. Сборка и сторонние пакеты не требуются.
Команды выполняются из каталога этой практики. Для проверки окна нужен рабочий
графический сеанс.

```bat
run.bat
python -B -m unittest discover -s tests -v
```

Пример интерактивного сеанса в окне «Эмулятор оболочки — Учебная VFS».

```text
$ ls -l /home
ls: ['-l', '/home']
$ cd /home
cd: ['/home']
$ unknown
Ошибка: unknown: команда не найдена
$ exit extra
Ошибка: exit: команда не принимает аргументы
$
```

Пустой ввод оставляет приглашение доступным. После ввода `exit`
окно закрывается.
