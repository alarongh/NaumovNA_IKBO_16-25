# Практическое занятие №1. Вариант 16

Выполнил — Наумов Никита Александрович.

Группа — ИКБО-16-25.

Тема — эмулятор командной оболочки UNIX-подобной ОС.

В эмуляторе можно просматривать файлы и каталоги из XML-образа, считать
их размер, менять права и владельца. Команды вводятся в окне Tkinter.
Изменения хранятся в памяти до закрытия окна.

## Этап 1. REPL

Введите команду в нижнее поле окна и нажмите Enter. Парсер делит строку
по пробельным символам. Кавычки и экранирование он не разбирает.
Пустая строка оставляет сеанс открытым, `exit` закрывает окно.

В [первом коммите практики][repl] команды `ls` и `cd` только печатают
своё имя и аргументы. Пример из окна «Эмулятор оболочки — Учебная VFS».

```text
$ ls -l /home
ls: ['-l', '/home']
$ cd /home
cd: ['/home']
$ unknown
Ошибка: unknown: команда не найдена
$ exit extra
Ошибка: exit: команда не принимает аргументы
$
```

## Запуск и проверка

Нужен Python 3.10 или новее с Tkinter. Сборка и установка сторонних
пакетов не требуются. Откройте терминал в каталоге этой практики.

```bat
run.bat
python -B -m unittest discover -s tests -v
```

В Linux команда запуска — `python3 -B src/main.py`. Для тестов окна
нужен графический сеанс. На Windows с Python 3.14.7 прошли 18 тестов,
в том числе ввод по Enter и закрытие окна по `exit`.

## Этап 2. Конфигурация

| Параметр | Назначение |
| --- | --- |
| `--vfs PATH` | Путь к XML-образу. По умолчанию открывается [deep.xml](examples/deep.xml). |
| `--startup PATH` | Путь к стартовому скрипту в UTF-8. Без параметра эмулятор ждёт ручного ввода. |

При запуске окно показывает абсолютный путь к образу и путь к скрипту,
если он задан. Скрипт пропускает пустые строки и текст после `#` в начале
строки или после пробельного символа. Каждая команда появляется в окне
вместе с ответом. Ошибка не прерывает скрипт, а `exit` завершает сеанс.

```bat
run.bat --help
run.bat --vfs examples\minimal.xml --startup examples\stage-2.txt
examples\stage-2-relative.bat
examples\stage-2-absolute.bat
```

Оба командных файла передают `--vfs` и `--startup`. Первый использует
относительные пути, второй — абсолютные.

## Этап 3. Виртуальная файловая система

Атрибут `name` элемента `<vfs>` задаёт имя в заголовке окна.
`<dir>` содержит вложенные каталоги и файлы. В `<file>` можно записать
текст в UTF-8 или данные в base64 с атрибутом `encoding="base64"`.

У каждого файла и каталога должно быть имя `name`, уникальное в своём
каталоге. В именах допустимы печатные символы без пробельных знаков и `/`.
Имена `.` и `..` зарезервированы. Права, владельца и группу можно задать
атрибутами `mode`, `owner` и `group`. По умолчанию у файлов права `644`,
у каталогов `755`, владелец и группа — `student:students`.


образа. Введите `exit`, чтобы закрыть текущее окно и перейти к следующему.

## Этап 4. Основные команды

| Команда | Действие |
| --- | --- |
| `ls [-al] [ПУТЬ]` | Показывает файл или содержимое каталога. `-a` включает скрытые имена, `-l` показывает права, владельца, группу и размер файла в байтах. |
| `cd [ПУТЬ]` | Переходит в каталог. Без аргументов возвращается в корень. |
| `pwd` | Показывает абсолютный путь текущего каталога. |
| `uname [-a]` | Выводит `Linux`, с флагом `-a` — `Linux vfs 1.0 emulator`. Это сведения об эмуляторе. |
| `du [-s] [ПУТЬ]` | Считает байты в файле или суммирует размеры файлов в каждом каталоге. С флагом `-s` выводит только итог. |

Путь с начальным `/` отсчитывается от корня, остальные пути — от текущего
каталога. `.` означает текущий каталог, `..` — родительский.
Если путь опущен, `ls` и `du` работают с текущим каталогом.
Для этих команд `--` отмечает конец флагов.

Запустите сценарий [stage-4.txt](examples/stage-4.txt).

```bat
run.bat --startup examples\stage-4.txt
```

В этом сеансе `du` показывает 3 байта для двоичного файла, а `cd`
сообщает об ошибке при попытке перейти в обычный файл.

```text
/home/student/docs $ du bytes.bin
3	/home/student/docs/bytes.bin
```

```text
/ $ cd /home/student/docs/readme.txt
Ошибка: cd: /home/student/docs/readme.txt: не каталог
```

## Этап 5. Права и владельцы

`chmod РЕЖИМ ПУТЬ [ПУТЬ ...]` меняет права файлов и каталогов. Режим
задаётся тремя или четырьмя восьмеричными цифрами, например `600` или
`1750`. В записи `u+x,g+r,o=` классы `u`, `g` и `o` означают владельца,
группу и остальных. Класс `a` или пропуск класса означает всех. Знаки
`+`, `-` и `=` добавляют, снимают и задают права `r`, `w`, `x`.
Правила через запятую выполняются слева направо.

`chown ВЛАДЕЛЕЦ[:ГРУППА] ПУТЬ [ПУТЬ ...]` меняет владельца или
владельца и группу вместе. Для смены только группы используется
`chown :ГРУППА ПУТЬ`. Имена начинаются с латинской буквы или `_`.
Дальше допустимы латинские буквы, цифры, `_`, `.` и `-`. Вместо имени
можно указать числовой идентификатор.

Обе команды проверяют все пути до изменения атрибутов. Права и владельцы
хранятся в памяти как метаданные VFS и отображаются в выводе `ls -l`.
При новом запуске эмулятор загружает исходные значения из XML.

```bat
run.bat --startup examples\stage-5.txt
```

Фрагмент [stage-5.txt](examples/stage-5.txt) после перехода в `docs`.

```text
/home/student/docs $ chmod 600 readme.txt
/home/student/docs $ ls -l readme.txt
-rw------- student students 5 readme.txt
/home/student/docs $ chmod u+x,g+r,o= readme.txt
/home/student/docs $ ls -l readme.txt
-rwxr----- student students 5 readme.txt
```
