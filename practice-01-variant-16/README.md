Тема — эмулятор командной оболочки UNIX-подобной ОС.

---

## Этап 1. REPL

Окно Tkinter показывает имя виртуальной файловой системы в заголовке.
Строка делится на команду и аргументы по пробельным символам.
Команда запускается клавишей Enter. Заглушки `ls` и `cd` выводят имя
и список полученных аргументов. `exit` закрывает окно.

## Запуск и проверка

Нужен Python 3.10 или новее с Tkinter. Сборка и сторонние пакеты не требуются.
Команды выполняются из каталога этой практики. Для проверки окна нужен рабочий
графический сеанс.

```bat
run.bat
python -B -m unittest discover -s tests -v
```

Пример интерактивного сеанса в окне «Эмулятор оболочки — Учебная VFS».

```text
$ ls -l /home
ls: ['-l', '/home']
$ cd /home
cd: ['/home']
$ unknown
Ошибка: unknown: команда не найдена
$ exit extra
Ошибка: exit: команда не принимает аргументы
$
```

Пустой ввод оставляет приглашение доступным. После ввода `exit`
окно закрывается.

## Этап 2. Конфигурация

`--vfs PATH` задаёт путь к образу VFS, `--startup PATH` задаёт путь
к стартовому скрипту. Окно показывает абсолютные пути при запуске.
Без параметров используется `examples/deep.xml` и открывается пустой сеанс.

Стартовый скрипт читается в UTF-8. Строка с `#` в начале или после
пробела считается комментарием с этого места. Пустые строки пропускаются.
Команды и их ответы появляются в окне по очереди. После ошибки сценарий
продолжается, а `exit` закрывает окно и останавливает сценарий.

```bat
run.bat --help
run.bat --vfs examples\minimal.xml --startup examples\stage-2.txt
examples\stage-2-relative.bat
examples\stage-2-absolute.bat
```

## Этап 3. Виртуальная файловая система

Имя из атрибута `name` корневого элемента `<vfs>` отображается
в заголовке окна. `<dir>` содержит вложенные каталоги и файлы.
У `<dir>` и `<file>` обязательно имя `name`, уникальное в каталоге.
Узлы могут содержать атрибуты `mode`, `owner` и `group`.
Текст `<file>` хранится в UTF-8, двоичные данные задаются атрибутом
`encoding="base64"`. Файл XML читается один раз, дерево хранится в памяти.

<details>
<summary>Примеры образов</summary>

| Образ | Содержимое |
| --- | --- |
| [minimal.xml](examples/minimal.xml) | Только корень |
| [files.xml](examples/files.xml) | Текстовый, двоичный и пустой файлы |
| [deep.xml](examples/deep.xml) | Три вложенных каталога и файлы внутри |

</details>

```bat
examples\stage-3-relative.bat
examples\stage-3-absolute.bat
```

Каждый командный файл открывает три окна по очереди. В каждом видны имя
VFS, количество каталогов и файлов, диалог из сценария
[stage-3.txt](examples/stage-3.txt) и сообщения об ошибках.
Для перехода к следующему образу введите `exit`.

## Этап 4. Основные команды

| Команда | Действие |
| --- | --- |
| `ls [-al] [ПУТЬ]` | Показать файл или содержимое каталога. `-a` включает скрытые имена, `-l` показывает права, владельца, группу и размер файла в байтах. |
| `cd [ПУТЬ]` | Перейти в каталог. Без аргументов перейти в корень. |
| `pwd` | Показать абсолютный путь текущего каталога. |
| `uname [-a]` | Показать условное имя системы или полную строку эмулятора. |
| `du [-s] [ПУТЬ]` | Показать сумму размеров файлов в байтах для каждого каталога. С `-s` показать только итог. Для файла выводится его размер. |

Абсолютные пути начинаются с `/`, относительные отсчитываются от текущего
каталога. `.` обозначает текущий каталог, `..` поднимает на уровень выше.
По умолчанию `ls` и `du` используют текущий каталог. Для этих команд
`--` отмечает конец флагов.

```bat
run.bat --startup examples\stage-4.txt
```

В [stage-4.txt](examples/stage-4.txt) показаны обычный и подробный списки,
переходы по дереву, размеры файлов и каталогов, сообщения при ошибочных
путях и флагах.
