## Этап 1. JSON и промежуточное представление

Язык программы представляет собой массив объектов с полями `op` и `b`.
Операции `load`, `read`, `store`, `popcnt` соответствуют кодам
1, 110, 12 и 54. Поле `b` является целым неотрицательным числом.
Для load допустимы 27 бит, для остальных команд 17 бит.

Пример одной команды.

```json
[{"op": "load", "b": 559}]
```

Python 3.10 или новее запускается из каталога практики.
Сборка и сторонние пакеты Python не требуются.

```powershell
New-Item -ItemType Directory -Force output
.\run.bat --source examples/spec.json --output output/spec.bin --test
python -B -m unittest discover -s tests -v
```

В версии этапа 1 тестовый режим выводит поля A и B.
Тесты из сборника записаны в examples/spec.json.
